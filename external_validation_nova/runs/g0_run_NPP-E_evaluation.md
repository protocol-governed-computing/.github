## Finding A — answered

The author separated the two cases from the text alone:

| | Count |
|---|---|
| **expressly permitted by source** (incl. *with author selection*) | **11** |
| **unresolved** / *unresolved by family, decided by author* / variants | **8** |
| **expressly required by source** (incl. *parameterized*, *with fixtures chosen*) | **5** |

*Expressly permitted* is the standard allowing a choice. *Unresolved by family* is the standard not
saying and the author having to. That is the distinction A says `6a` does not support, drawn by an
author who was never shown it.

**What rules out recall.** This author extended the claim-type vocabulary — as run 2 did — but with
different constructions: `unresolved by family, decided by author`, `expressly required by source,
parameterized by author`. Run 2 coined `expressly required by source that the profile decide`. Same
underlying distinction, different labels. **Recall reproduces phrasing; derivation reproduces
structure.**

Across the three runs: run 1 was handed the distinction, run 2 held it from run 1, run 3 derived it.
**A is answered against this revision.** One author and one scope, so not conclusive — but the
instrument is now clean and the result is positive where two runs could produce none.

## Finding F — the standard determines no vocabulary at all

Three closures from identical text under identical scope:

| Run | Closed vocabulary |
|---|---|
| `NPP-C` | platform-root · snapshot · inspection-surface · evidence-record |
| `NPP-D` | governance-root · snapshot · read-operation · evidence-record |
| `NPP-E` | constitution · governance-element · **workflow** · **capability-contract** · read-operation |

**`NPP-E` diverges from both.** It closes five rather than four, drops snapshot and evidence-record
as kinds, and introduces **workflow** and **capability-contract** — two concepts neither earlier run
reached, and two the reference realization does carry.

This corroborates the carry-over diagnosis from the other side: C and D match each other because D
remembered C. The one run that could not remember landed somewhere else.

**The result is stronger than *four, not nine*.** Two clean derivations from one text under one
scope produce different closures. The standard does not determine the set — and by `2d` §1 it is
not supposed to: *"a family that named its kinds would admit exactly one platform, and PGC admits
as many as there are profiles."* Variation is the specified behaviour, not a defect.

**That settles F against putting the nine in the ontology.** A set the standard deliberately
declines to determine cannot be a canonical axis of it. Where such a set belongs is a profile —
which is what `2d` already says, and what the runs demonstrate by closing different ones.

It remains true that all three runs share one model. A different reader would strengthen every line
above. It would not change the divergence, which is now observed within the same reader.
