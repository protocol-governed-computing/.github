# Run conditions — the models, and which role each performed

Recorded because the programme captured it nowhere. Every other condition of a run is written down
— the frozen family revision, the permitted and prohibited inputs, the staged environment, the
isolation regime — and the identity of the model performing the work was the one fact carried only
in the operator's memory. A replication cannot be attempted without it, and a claim about
independence cannot be assessed without it.

## Two roles, two models

| Role | Model | Harness |
|---|---|---|
| **Worker** — authored the profiles, built the realization, performed the transformation | **Claude Haiku 4.5** | GitHub Copilot |
| **Commissioning and evaluating side** — wrote the commissions and instruments, classified findings, dispositioned them, devised and ran the mutations | **Claude Opus 5** | agentic coding harness |

No sampling parameters were set by the operator in either harness.

## Which runs

All five worker runs used the worker model above: the three G0 profile authorings (`NPP-C`,
`NPP-D`, `NPP-E`), the G2 realization, and the G4 transformation.

## What the separation provides

**The evaluation was not performed by the party that produced the artifacts.** A worker that
classifies its own output cannot report a gap it failed to notice while producing it, which is why
the finding classification, the dispositions and the evaluations are all commissioning-side acts.

**The mutations were devised by a different model from the one whose demonstrations they defeated.**
This is the condition under which the two vacuous guards were found — a required digest downgraded
and a grounding guard disabled, each passing every demonstration written for it. A same-model check
would have been a system testing its own blind spot.

## What it does not provide

**Worker diversity.** One model performed every worker run, so the divergence observed at G0 between
the uncontaminated run and the two sharing a context is a divergence *within* one worker model. That
is the strongest evidence available here that the closure was derived rather than recalled, and it
is weaker than a genuinely different reader would be. A second worker model, or a person, remains
the single change that would most strengthen the programme's results.

**Anything about model versions over time.** The runs were performed across several sessions. The
attribution above is the operator's, given after the fact; nothing in the run artifacts records it
independently.

## For the next cycle

A run is not fully recorded until this file names the model for it. Capture it at commissioning
time, in the run's own record, rather than reconstructing it afterwards.
