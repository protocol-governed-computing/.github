# Commission Scope Register

This register records only what the commissioning task fixed. These are not determinations made by NPP-D and must not be cited as decisions settled by the family.

## Scope S-1

**Matter:** Profile identity for this run.

**Source basis:** Commission §1; `REVISION`.

**Claim type:** expressly required by source, where “source” is the commission rather than the family.

**Reasoning:** The commission says the identity is the one given for the run and identifies this run as NPP-D through the new archive/task designation. The family does not determine this identity.

**Confidence:** high

## Scope S-2

**Matter:** Profile a single governed system that is sealed and executed against governed state, with one snapshot accepted whole.

**Claim type:** expressly required by source, where “source” is the commission rather than the family.

**Reasoning:** The commission fixes this as the system class. It is not evidence that the family chose one snapshot or one system as its universal platform.

**Confidence:** high
