release 13 — a publication nobody outside can name is not available for use

This cycle changes nothing about what the platform does. It changes whether the platform can be
named by someone who was not part of building it, which is the precondition for every instrument the
project has left.

Cycle 12 ran the programme this project had been building toward: independent parties authoring
against the standard alone, building a system from it, driving that system from what it sealed, and
evolving it through its own transformation semantics. That result is recorded in `release-12.md`,
and it is the substance this cycle publishes. Cycle 12 was cut and not published; the composition
ordinal advanced and the public identity did not. This cycle issues `v2` and carries cycle 12's work
under it.

## What was actually done

**Every repository declares its own deposit metadata.** Ten `.zenodo.json` files — the nine
composition repositories that carry executable surface, and `standards`, which is outside the release
cycle and carries its own revision identity. Each declares title, description, author with ORCID,
licence and keywords.

`.github` deliberately has none. It carries the release process and the assembly contract, not a
component of the reference implementation, and a citable identity for it would name a thing nobody
should cite.

**The standard became citable first.** `standards` was archived at revision `v0` and carries a
version DOI, `10.5281/zenodo.22150616`, distinct from the concept DOI that resolves to whatever the
family later becomes. A claim names the revision it was made against, so it names the version. The
concept DOI reaches the standard; it does not name one.

**Its `CITATION.cff` was missing an ORCID.** The author was identified by name, alias and email, none
of which is a resolvable identity. Added.

## Why this is not bookkeeping

`v1` was archivable and not citable. Anyone could have archived it, and the archive would have been
attributed by inference — a repository name, a platform username, a licence guessed from a file. An
identity assembled by inference is the thing this family objects to everywhere else, and it is no
more acceptable when the subject is the publication itself than when it is a governed artifact.

The distinction the project keeps making about its own artifacts now holds for the artifacts
themselves: **declared, not inferred.**

## What this release is for

The last cycle closed the last thing the project could do to itself. What remains requires someone
who was not part of building it — and someone who was not part of building it has to be able to name
what they examined, at the revision they examined it, without asking the people who built it.

That is the whole of this cycle. It is the smallest change in the project's history and the one that
makes the previous cycle's result usable by anyone else.
